Before the first manual run

  1. Review the workflow timezone and what 08:00 means for your schedule.
  2. Confirm both OAuth credentials allow HTTP requests only to the required domains.
  3. Run the Manual Trigger and inspect the created spreadsheet. Publish only after that test.

OAuth access tokens stay in this tab's memory and are sent for active requests to the selected n8n workspace and the same-origin MEKA installer relay. The relay does not store them. This page has no analytics or third-party scripts.

Apify and n8n Cloud may charge for their services. The workflow stays inactive until you publish it.
